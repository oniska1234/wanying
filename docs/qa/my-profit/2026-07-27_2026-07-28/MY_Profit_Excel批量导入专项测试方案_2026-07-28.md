# MY Profit Excel 批量导入专项测试方案

- 项目：MY Profit 跨境电商利润工具（TikTok Shop Malaysia）
- 功能：Excel 模板下载、批量解析、服务端计算、事务保存
- 版本基线：Commit `59bc693`
- 测试环境：生产 IP 环境 `https://47.106.167.145`
- 制定日期：2026-07-28

## 1. 测试目标

验证以下业务闭环：

1. 登录用户可以下载结构正确的 Excel 模板；
2. 用户按模板填写后，可以一次上传并获得逐行结果；
3. 每一行均经过与单条保存一致的字段校验；
4. 计算只在服务端执行，费率、汇率、类目匹配和风险提示正确；
5. 合法行持久化，非法行不落库，部分失败不影响其他合法行；
6. 免费版 10 条额度、100 行上限和并发锁不能绕过；
7. 用户之间的数据严格隔离；
8. 异常文件不会导致 500、脏数据或不明确的错误。

## 2. 测试范围

### 包含

- `/api/my-profit/import/template`
- `/api/my-profit/import`
- `/my-profit/import`
- 计算器、用户菜单、选品清单中的导入入口
- Excel 解析、字段映射、逐行校验、计算、保存
- 费率匹配层级和未知类目警告
- 免费额度、事务、并发、数据隔离
- 失败结果、行号、字段和错误信息

### 不包含

- 付费订阅、支付和兑换码本身；
- 管理后台费率规则的增删改；
- Excel 之外的批量导出；
- 域名和公众可信 TLS 证书验收；
- 百万级数据压测。产品单次上限为 100 行，本轮只测试该业务边界。

## 4. 测试数据设计

所有商品名使用 `QA-XLS-` 前缀，便于隔离和清理。

| 数据文件 | 用途 | 关键内容 |
|---|---|---|
| `qa-xls-baseline.xlsx` | 标准成功链路 | 1 条合法商品，精确类目 |
| `qa-xls-mixed.xlsx` | 部分成功 | 合法行、负售价、折扣超价、小数数量、非法币种、未知类目、超长名称、空名称、100% 比例 |
| `qa-xls-validation.xlsx` | 非法值矩阵 | 数量 0/负数/文本、非法店铺类型、非法 BXP、比例越界、汇率 0、负成本、文本售价、空白名称 |
| `qa-xls-100.xlsx` | 上限与额度 | 100 条合法数据 |
| `qa-xls-101.xlsx` | 超上限 | 101 条合法数据 |
| `qa-xls-concurrent-A/B.xlsx` | 并发锁 | 两个文件各 10 条合法数据 |
| `qa-xls-wrong-header.xlsx` | 表头异常 | 首列表头被修改 |
| `qa-xls-corrupt.xlsx` | 损坏文件 | 非 XLSX 内容 |
| 原始模板 | 空数据行为 | 只含示例行和说明行 |

标准计算基准：

```text
原价 RM100
卖家折扣 RM10
平台折扣 RM20
买家运费 RM5
数量 1
成本全部为 0
店铺 MARKETPLACE
BXP
类目 Electronics > Phone Accessories
```

期望关键结果：

```text
卖家总收入 RM95
平台费 RM10.449
净利润 RM84.551
类目匹配 exact
平台折扣不减少卖家收入
```

## 5. 核心测试用例

### A. 模板与入口

| 编号 | 场景 | 期望 |
|---|---|---|
| XLS-TPL-001 | 登录后下载模板 | HTTP 200，文件名和 MIME 正确 |
| XLS-TPL-002 | 检查工作簿 | 有效 XLSX，两个 Sheet |
| XLS-TPL-003 | 检查选品数据表 | 21 列，列名和顺序正确 |
| XLS-TPL-004 | 检查字段说明表 | 21 个字段均有说明 |
| XLS-AUTH-001 | 未登录访问导入页 | 307 跳转登录 |
| XLS-AUTH-002 | 未登录下载模板 | 401 |
| XLS-AUTH-003 | 未登录上传 | 401 |
| XLS-UI-001 | 三处导航入口 | 路由正确、可进入导入页 |

### B. 文件级校验

| 编号 | 场景 | 期望 |
|---|---|---|
| XLS-FILE-001 | 合法 `.xlsx` | 正常解析 |
| XLS-FILE-002 | 无 multipart/file | 400，明确提示 |
| XLS-FILE-003 | 损坏 XLSX | 400，不出现 500 |
| XLS-FILE-004 | 非 Excel 文件 | 400/415，文件级拒绝 |
| XLS-FILE-005 | 表头缺失或错误 | 文件级拒绝，指出缺失表头 |
| XLS-FILE-006 | 模板未填写 | 400，提示没有有效数据 |
| XLS-FILE-007 | 100 行 | 接受并处理 |
| XLS-FILE-008 | 101 行 | 400，提示最多 100 行 |

### C. 行级校验

| 字段 | 有效值 | 无效/边界值 |
|---|---|---|
| 商品名称 | 普通中文、马来文 | 空白、仅空格、101 字以上 |
| 商品原价 | 正数、小数 | 0、负数、文本 |
| 各折扣 | 0、合法小数 | 负数、卖家折扣大于原价 |
| 数量 | 1、100 | 0、负数、小数、文本 |
| 成本币种 | CNY、MYR | USD、空值、大小写变体 |
| 成本项 | 0、正数 | 负数、文本 |
| 比例 | 0、100、小数 | -1、101、文本 |
| 汇率 | 正数 | 0、负数、文本 |
| 店铺类型 | MARKETPLACE、MALL | 未知枚举 |
| BXP 状态 | BXP、NON_BXP、UNCERTAIN | 未知枚举 |
| 类目 | 精确、父级、空、未知 | 未知类目应使用默认费率并警告 |

原则：非法值必须逐行失败，不能静默取整、截断、改成默认值或落库。

### D. 计算、保存与结果

| 编号 | 场景 | 期望 |
|---|---|---|
| XLS-CALC-001 | 标准基准行 | 结果与基准完全一致 |
| XLS-CALC-002 | 精确类目 | `matchLevel=exact` |
| XLS-CALC-003 | 未知类目 | `matchLevel=default` 且保存风险警告 |
| XLS-SAVE-001 | 混合成功/失败 | 合法行保存，非法行不保存 |
| XLS-SAVE-002 | 错误定位 | 返回真实 Excel 行号、字段、消息 |
| XLS-SAVE-003 | 刷新后读取 | 输入与结果快照持久化 |

### E. 额度、并发和隔离

| 编号 | 场景 | 期望 |
|---|---|---|
| XLS-QUOTA-001 | 免费账号上传 100 条 | 只保存剩余额度，`quotaHit=true` |
| XLS-QUOTA-002 | 两个 10 行文件并发上传 | 最终最多 10 条 |
| XLS-QUOTA-003 | 失败明细 | `failed` 与可追溯明细一致 |
| XLS-SEC-001 | 用户 B 读取用户 A 导入商品 | 404 |
| XLS-CLEAN-001 | 清理测试数据 | 仅删除 `QA-XLS-` 数据，最终为 0 |

## 6. 准入与退出标准

上线准入：

- P0/P1 缺陷为 0；
- 非法输入不得被静默转换并保存；
- 100/101 行、免费额度和并发锁通过；
- 标准计算结果正确；
- 未登录和跨用户访问被拒绝；
- API 不出现 500；
- 可信证书环境下完成 Chrome、Edge、Safari 的上传和结果展示。

测试退出：

- 所有核心用例已执行；
- 缺陷有复现数据和证据；
- `QA-XLS-` 商品已清理；
- 修复后重新执行所有失败项，并回归标准成功链路、额度与并发。
