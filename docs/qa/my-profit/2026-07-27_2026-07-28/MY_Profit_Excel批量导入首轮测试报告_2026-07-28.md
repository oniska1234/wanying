## 1. 执行结论

主链路已经具备：

- 模板可下载，文件结构正确；
- 合法 Excel 可以解析、计算并保存；
- 标准计算结果正确；
- 合法行与非法行可以部分成功；
- 100/101 行边界正确；
- 免费版 10 条额度和并发锁有效；

但批量导入与单条保存的字段校验仍不一致。若用户输入部分非法值，系统会静默改成默认值后保存，造成不可见的数据失真和利润误算风险。

缺陷汇总：

| 严重级别 | 数量 | 结论 |
|---|---:|---|
| P0 | 0 | 无服务不可用或权限绕过 |

| 7 | `sellerDiscount` | 卖家折扣不能大于商品原价 |
| 12 | 商品名称 | 商品名称必填 |

边界校验正确的项目：

- 达人佣金 101% 被拒绝；
- 广告费 -1% 被拒绝；
- 退款率 101% 被拒绝；
- 汇率 0 被拒绝；
- 采购成本为负被拒绝；
- 文本售价被拒绝；
- 空白名称被拒绝；
- 100% 比例边界被接受；
- 未知类目使用 `matchLevel=default`，警告已保存；
- 精确类目使用 `matchLevel=exact`。

## 5. P1 缺陷：非法值被静默转换并保存

### 现象

以下输入没有逐行失败，而是被改写后落库：

| 原始 Excel 值 | 实际保存值 |
|---|---|
| 数量 `1.5` | `2` |
| 数量 `0` | `1` |
| 数量 `-1` | `1` |
| 数量 `abc` | `1` |
| 成本币种 `USD` | `CNY` |
| 店铺类型 `INVALID` | `MARKETPLACE` |
| BXP 状态 `INVALID` | `NON_BXP` |
| 104 字商品名 | 静默截断为 100 字 |

小写 `cny` 被规范化为 `CNY` 可以接受，但未知枚举和非法数量不应使用同一套默认化逻辑。

### 风险

- 用户认为 Excel 原值已经保存，实际数据库值不同；
- 数量、币种、店铺类型和 BXP 状态会改变成本、费率或利润；
- 无错误信息，用户无法发现和纠正；
- 超长名称静默截断可能造成名称碰撞和识别错误；
- 与“复用 `validateForm` 全链路”的设计目标不一致。

### 修复建议

解析层只做无损转换：

```text
去除首尾空格
允许明确的大小写归一化
数字字符串转为数字
```

以下情况必须在进入 `buildInput/calculate` 前返回行级错误，禁止兜底：

```text
quantity 不是正整数
costCurrency 不在 CNY/MYR
shopType 不在 MARKETPLACE/MALL
bxpStatus 不在 BXP/NON_BXP/UNCERTAIN
name 长度超过 100
```

建议为批量导入增加与单条保存共享的 schema，并加入这些回归测试，避免两条链路再次漂移。

## 6. 文件级校验

| 场景 | 实际结果 | 判定 |
|---|---|---|
| 缺少 multipart/file | HTTP 400，明确提示 | 通过 |
| 损坏 `.xlsx` | HTTP 400，无 500 | 通过 |
| 101 行 | HTTP 400，提示当前 101 行、最多 100 行 | 通过 |
| 100 行 | 正常解析 | 通过 |
| 错误表头 | HTTP 200，退化为逐行“商品名称必填” | P2 |
| 文本文件 | HTTP 200，尝试按工作簿解析后逐行失败 | P2 |

错误表头和非 Excel 文件虽然没有产生脏数据，但不应进入逐行计算。建议先校验：

- 扩展名和 MIME；
- XLSX ZIP/工作簿结构；
- 必需 Sheet；
- 21 个表头及顺序；
- 缺失/重复表头。

失败时返回单一文件级 400 错误，例如“缺少表头：商品名称”。

## 7. 100 行、免费额度与并发

### 7.1 101 行

```json
{"error":"单次最多导入 100 行，当前 101 行"}
```

HTTP 400，未保存数据。结果：通过。

### 7.2 免费账号导入 100 行

```text
total: 100
success: 10
failed: 90
quotaHit: true
最终商品数: 10
```

结果：额度限制通过。

可追溯性问题：

- 90 条额度失败全部返回 `row: 0`；
- `failed=90`，但 `errors` 仅返回 50 条；
- 用户无法仅凭结构化行号定位未导入的 Excel 行。

建议返回：

```text
真实 Excel 行号
完整失败明细，或 errorsTruncated/errorsTotal 字段
清晰说明只保存了前 N 条
```

### 7.3 并发双上传

同一空免费账号并发上传 A、B 两份文件，每份 10 条：

```text
A: success 10, failed 0
B: success 0, failed 10, quotaHit true
最终商品数: 10
```

`pg_advisory_xact_lock` 生效，没有超出免费额度。结果：通过。

## 9. UI 验收状态

- 导入页 HTTP 200；
- “Excel 批量导入”“下载模板”“拖拽”等主要文案存在；

这属于已知环境阻塞，不计为本功能代码失败。域名备案和可信证书完成后应补测 Chrome、Edge、Safari。
