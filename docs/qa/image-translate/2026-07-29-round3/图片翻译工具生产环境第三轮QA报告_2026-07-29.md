## 8. 遗留风险和建议

### P1：处理中任务不能跨服务重启恢复

Python 服务仍使用内存字典保存任务：

```python
tasks: dict[str, dict] = {}
```

服务重启后，Next.js 会将找不到的任务标记失败，避免永久 processing，但不能从断点恢复。建议引入 Redis/数据库队列，并使单图处理幂等、可重试。

### P2：生产运维项

正式发布前建议完成：

1. 备案域名切换并配置受信任 HTTPS 证书；
2. Commit、Push、构建并按明确 commit 重新部署；
3. 配置 OSS 生命周期或提供用户历史删除功能；
4. 配置 PM2/应用日志轮转；
5. 统一 Nginx、API 和前端的单任务总大小；
6. 用 30–50 张真实 1688 商品图建立人工金标集。
