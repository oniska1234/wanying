# 图片翻译工具云端迁移专项测试方案

- 产品：中文商品图片 → 马来文商品图片
- 数据来源：1688 商品图片
- 目标环境：wanying 服务器（最终域名/路由待部署完成后确认）
- 制定日期：2026-07-28
- 测试类型：云端迁移、会员化、多用户、OSS 持久化、图片质量专项

## 1. 测试目标

本次 QA 不只验证“能上传、能翻译”，还要证明本地单用户工具迁移到云端后满足：

1. 只有符合产品规则的会员可以使用；
2. 多个会员同时使用时，任务、图片和下载结果严格隔离；
3. 原图、结果图和历史记录持久化到 OSS；
4. 容器重启、页面刷新或用户重新登录后，历史任务仍可恢复；
5. 本地临时文件不会持续占用服务器磁盘；
6. 1688 商品图中的中文可以正确识别、翻译和重绘；
7. 商品主体、颜色、尺寸、商标和布局不会被错误破坏；
8. 大文件、伪造图片、同名文件和并发任务不会污染数据或拖垮服务；
9. OSS 和 AI 调用成本可控；
10. 错误信息对普通会员可理解、可重试。

## 2. 测试准入条件

正式执行前需满足：

- 页面实际部署在 wanying 服务器；
- 域名或 IP 路由与目标服务器一致；
- 前端、后端、处理微服务、PostgreSQL、OSS 均可访问；
- 至少准备两个普通会员账号；
- 如存在非会员/过期会员状态，准备一个对应账号；
- 准备独立 QA OSS 前缀或允许使用 `image-translate/qa-*` 前缀；
- 允许创建并清理 QA 任务；
- 所有线上密钥来自环境变量或密钥管理服务，不保存在源码/镜像中。

## 3. 静态预检风险

以下结论来自迁移源码副本，最终以 wanying 部署版本复核为准。

### SEC-P0-001：源码存在硬编码 AI API 密钥

配置文件含看似有效的默认 API 密钥。风险包括：

- Git 历史、镜像层、构建日志或归档泄露；
- 未授权调用和费用损失；
- 即使生产环境变量覆盖，源码中的旧密钥仍可能有效。

上线前要求：

1. 立即轮换该密钥；
2. 删除源码默认值，只允许环境变量注入；
3. 检查 Git 历史和 Docker 镜像层；
4. 查看调用账单和异常 IP；
5. 报告和日志中不得输出密钥。

### AUTH-P1-001：仅见登录鉴权，未见会员资格校验

当前路由使用 `get_current_user`，但没有看到：

- 会员是否有效；
- 套餐是否允许使用图片翻译；
- 到期会员是否被拒绝；
- 管理员、普通会员、免费用户的差异。

需要验证并补充统一 entitlement/feature gate。

### TASK-P1-001：微服务任务状态保存在进程内存

任务状态使用进程内字典：

- 容器重启后任务状态丢失；
- 后端数据库可能永久停在 `processing`；
- 多副本部署时，不同实例无法读取彼此任务；
- 无法可靠恢复中断任务。

建议使用数据库/Redis/任务队列保存状态，并设计重试或失败回收。

### FILE-P1-001：文件只校验扩展名

当前未见：

- 单文件大小上限；
- 请求总大小上限；
- MIME/文件签名校验；
- 像素数量上限；
- 解码炸弹防护；
- EXIF/异常图片处理。

伪造扩展名文件可能先进入 OSS，再在处理阶段失败。

### FILE-P1-002：同名文件和同 stem 文件可能覆盖

OSS 输入 key 直接使用原文件名，输出使用原文件 stem：

```text
a.jpg + a.jpg
a.jpg + a.png
```

可能造成输入覆盖、输出覆盖、数据库 item 映射错误或 ZIP 重名。

### OSS-P1-001：输出上传失败可能仍被标记成功

处理服务在 OSS 输出上传失败时仍可能返回图片处理成功，但 `output_key` 为空。前端会显示任务完成，却没有结果图可下载。

### DOWNLOAD-P1-001：下载 token 放入 URL

前端下载使用：

```text
/download/{task_id}?token=...
```

风险：

- token 进入浏览器历史；
- 进入 Nginx/access log；
- 可能通过 Referer 泄露；
- 如果后端只接受 Authorization Header，下载还可能直接 401。

建议使用短期一次性下载 URL，或通过带 Authorization Header 的请求下载 Blob。

### QUALITY-P1-001：所有输出强制转为 800×800

方图主图可能适合，但 1688 长详情图会被整体缩进 800×800：

- 750×3000/4000 长图文字会变得不可读；
- 四周产生大量白边；
- OCR 二次处理可能受缩放影响；
- 原始布局和平台用途改变。

需要明确产品范围：

- 如果只支持商品主图，前端应明确限制；
- 如果支持详情图，应保持纵横比和可读分辨率，不应强制方图。

### OPS-P2-001：临时文件和日志策略需复核

- 代码注释称临时文件保留 1 小时，实际任务结束立即删除；
- 日志使用普通 `FileHandler`，未见滚动和保留上限；
- OSS 未见生命周期和用户删除入口；
- 数据库未见历史清理策略。

## 7. OSS 与服务器存储

### 7.1 OSS

验证对象结构：

```text
image-translate/{user_id}/{task_uid}/input/{unique_file_id}
image-translate/{user_id}/{task_uid}/output/{unique_file_id}
```

检查：

- Bucket 为私有；
- AK/SK 不暴露给浏览器；
- 原图和结果图均有对象；
- 数据库 key 与 OSS 对象一致；
- 不存在跨用户前缀；
- 签名 URL 有合理短时有效期；
- 上传失败、处理失败和删除任务时不会留下孤儿对象；
- 生命周期规则符合产品历史保存策略；
- OSS CORS 只允许需要的域名和方法；
- 服务账号只拥有必要前缀权限。

### 7.2 服务器磁盘

任务前后记录：

```text
容器可写层大小
临时目录文件数和空间
服务日志大小
磁盘可用空间
```

验收：

- 任务完成后临时原图/结果图被清理；
- 失败任务也清理；
- 容器重启后无遗留大文件；
- 日志有滚动、大小和保留上限；
- 历史记录只依赖数据库 + OSS，不依赖本地文件。

## 8. 图片质量验收

### 8.1 OCR

建议指标：

- 简单大字图中文召回率 ≥ 95%；
- 普通卖点图中文召回率 ≥ 90%；
- 密集/低清图中文召回率 ≥ 80%；
- 数字、型号和单位保留正确率 ≥ 99%。

### 8.2 翻译

人工复核：

- 语义正确；
- 使用马来西亚电商表达，不混入印尼语；
- 品类、材质、颜色、尺寸、数量准确；
- 不凭空增加功效、认证或承诺；
- 品牌、型号、单位不误译；
- 同一术语在同一批次保持一致。

### 8.3 重绘

- 马来文不越界、不遮挡商品；
- 字体大小可读；
- 背景修复无明显色块、重复纹理或断裂；
- 商品主体、颜色和结构不被修改；
- 结果图不残留应翻译的中文；
- 原图比例和目标平台规格符合产品定义；
- 无文字图不应产生虚假文字；
- 去品牌/水印行为必须符合明确的用户选择和平台合规要求。

## 10. 退出标准

上线准入：

- P0/P1 为 0；
- 硬编码密钥已轮换并从源码/镜像移除；
- 会员资格控制和多用户隔离通过；
- 容器重启后任务不会永久卡住；
- OSS 上传失败不会标记成功；
- 文件大小、真实格式和像素上限有效；
- 同名文件不覆盖；
- 下载不在 URL 暴露长期 token；
- 1688 样本的 OCR、翻译和重绘达到质量指标；
- 服务器任务后无图片残留；
- 历史记录可从数据库 + OSS 恢复；
- 所有 QA 任务和 OSS 测试对象可完整清理。
